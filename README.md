# Biblia Viva

App Android de lectura bíblica (estilo Biblia Todo): versículo del día, lectura por libro y capítulo, búsqueda, favoritos, resaltados, notas, planes de lectura, diario de oración, audio con la voz del celular e imágenes para compartir.

- Texto incluido: Reina-Valera 1909 completa (dominio público), tomada de scrollmapper/bible_databases, con ortografía levemente actualizada.
- Desde **Ajustes → Importar Biblia completa** se puede cargar un archivo .json con otra versión (por ejemplo, la RVR1960, que requiere licencia de Sociedades Bíblicas Unidas para distribuirla).

## Cómo obtener el APK
Cada vez que se sube un cambio a `main`, GitHub Actions compila la app y la publica en **Releases** como `BibliaViva.apk`.
